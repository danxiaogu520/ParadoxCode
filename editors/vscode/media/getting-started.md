# Start using ParadoxCode

Use the **Start using ParadoxCode** walkthrough on this page. It guides workspace trust,
opening a Mod, server installation, and selecting local Vanilla data. Its labels and actions
come from the extension manifest and localization bundles.

The [extension guide](https://github.com/danxiaogu520/ParadoxCode/blob/main/editors/vscode/README.md)
explains editor workflows and troubleshooting. The
[settings and command reference](https://github.com/danxiaogu520/ParadoxCode/blob/main/editors/vscode/REFERENCE.md)
is generated from the manifest used by VS Code.

No game installation, Vanilla cache, or user Mod is included with ParadoxCode.

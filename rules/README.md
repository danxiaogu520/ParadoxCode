# EU4 rules

This project supports EU4 only. `eu4.pdxrules` is generated by `pdx-cwt import` from the explicit
research corpus and loaded read-only by `pdx-rules` for the `pdx-game-eu4` profile; the companion
`manifest.json` records `game_id`, source file hashes, importer version, schema version, and the
canonical logical `rule_hash`. The
`import-report.json` is a human-readable provenance/count report. CWT is never a runtime
dependency, and Vanilla files or Vanilla index caches are never committed.

The current artifact is schema 12, produced by importer
`phase-rules-game-id-1`, from 73 pinned EU4 CWT inputs. It preserves duplicate
rules and alternative identities, node/leaf/leaf-value/value-clause shapes, cardinality and
scope directives, documentation, dynamic value matchers, and EU4 type path metadata. The runtime
loads the normalized artifact and does not parse CWT at startup.

Regenerate and validate locally:

```text
cargo run -p pdx-cwt -- import \
  --source reference/cwtools-eu4-config \
  --output rules/eu4.pdxrules \
  --manifest rules/manifest.json \
  --report rules/import-report.json
```

The current canonical `rule_hash` is
`446f21f2c08d8d802c8769df34259f880bb63467726592d3f95ee1cea7b71484`; the importer report is the
semantic inventory and provenance record for the committed database.

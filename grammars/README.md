# Tree-sitter grammars

The PdxScript and localisation directories below are the monorepo source-of-truth locations for
the Phase 1 semantic-neutral grammars. The CSV directory is an editor-only presentation grammar;
the authoritative CSV parser facade lives in `crates/pdx-syntax`.

- `tree-sitter-pdx-script`
- `tree-sitter-pdx-eu4-localisation`
- `tree-sitter-pdx-eu4-csv`
